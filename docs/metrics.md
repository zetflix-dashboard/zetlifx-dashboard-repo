# Метрики и фильтры

Источники определений — инструкция к датасету и проверенные схемы Parquet. Для каждой реализованной метрики фиксируй источник, формулу, единицу, поле даты, детализацию, применимые фильтры и контрольный пример. Заполняй определения по мере реализации графиков.

## Что проверить при первом расчёте

- Уточни, признаётся ли сумма как выручка или отражается как движение денег. Годовые подписки распределяй по месяцам признания согласно инструкции к датасету. Проверь правила для тестовых аккаунтов и партнёрской выручки.
- Сверяй финансовые итоги с PL_Control и Cash_Control в сопоставимом периоде и на сопоставимом уровне детализации.
- Для уникальных пользователей считай distinct на уровне выбранного среза. Проверь, может ли пользователь принадлежать нескольким сегментам.
- При объединении таблиц событий проверь ключи и детализацию, чтобы JOIN не размножил строки и суммы.
- Применяй фильтр только при наличии обоснованной связи с показателем. Например, общие расходы нельзя распределить по устройствам без согласованной методики.
