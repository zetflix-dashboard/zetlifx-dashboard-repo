# Редактор дашборда

## Изменение макета

Нажмите «Настроить» справа в верхней панели. Снизу появятся «Добавить график», «Добавить заголовок», отмена и повтор. Перетаскивайте карточку за значок с шестью точками или меняйте размер за её край. При фокусе на значке стрелки перемещают карточку, а Shift+стрелки меняют размер. Ctrl/Cmd+Z и Shift+Ctrl/Cmd+Z работают вне полей ввода и модальных окон. Кнопка × убирает экземпляр карточки из текущего пространства.

Когда закончите, нажмите «Сохранить». Изменения сразу останутся у вас на экране, а в углу на время отправки появится «Синхронизация…». После записи дашборд проверит, что сохранённый макет читается без ключа, и на несколько секунд покажет «Доступно команде». Макет в других вкладках того же браузера обновится при сохранении. Активные вкладки коллег проверяют обновления каждые 10 секунд, а скрытые — при возвращении на вкладку.

## Доступ к сохранению

При первом сохранении подключите GitHub. Создайте [fine-grained токен](https://github.com/settings/personal-access-tokens/new) с доступом к репозиторию, указанному в окне подключения, и разрешением Contents: Read and write. Если организация требует одобрения токена, дождитесь его. Дашборд запоминает ключ до закрытия вкладки. Для просмотра общего макета в текущей конфигурации ключ не нужен.

## Восстановление правок

При потере связи дашборд сохраняет отправленные правки в браузере и повторяет запрос. Если GitHub попросит подключиться снова, используйте кнопку в уведомлении. Независимые правки коллег объединяются автоматически. При конфликте действие «Открыть актуальный макет» скачивает ваши правки в JSON и открывает последнюю общую версию.

В меню пространств есть экспорт текущего макета и импорт JSON с подтверждением. Импорт применяется в редакторе и попадёт в общий макет после «Сохранить». Если в браузере остался старый черновик, выберите «Скачать прежние правки». Изменения из старого черновика можно перенести в общий макет вручную или импортировать целиком.

## Каталог проекта

«Графики» в верхней панели открывает перечень активных графиков проекта. В каждой строке показаны тип, условная пиктограмма и копируемый ID для обсуждения с ИИ, например `financial-trend`. ID берётся из части имени каталога после C-ID и должен быть уникален. Сохраняйте его при изменении отображаемого названия. Кнопка с карандашом меняет общее отображаемое название в каталоге, окне добавления и на дашборде. Чтобы вернуть исходное название, введите название из декларации графика. Первое переименование переводит файл макета на формат 4.

«Удалить из проекта» сохраняет C-ID в общем списке удалённых графиков. Старые открытые вкладки нужно обновить после перехода на новый формат макета. График исчезнет из каталога, окна добавления и всех пространств команды. Определение в `src/charts/` хранится в Git и резервирует свой C-ID. При подборе или редактировании графика учитывайте `removedCharts` в `workspace.json` ветки `workspace-sync`. Администратор может вернуть график, удалив его C-ID из этого списка отдельным изменением в Git. Ранее удалённые экземпляры можно добавить в пространства заново.
