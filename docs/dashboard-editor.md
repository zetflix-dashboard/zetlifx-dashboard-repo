# Пространства и редактор

Верхние вкладки — независимые пространства. «+» создаёт любое название; «Ещё» позволяет переименовать, удалить, экспортировать и импортировать. Вкладки переключаются стрелками + Enter/Space; Home/End переводят фокус на крайние вкладки.

«Настроить» открывает добавление, undo/redo и элементы управления карточками. Перетаскивайте за «Переместить», меняйте размер за нижний правый угол. Клавиатура на «Переместить»: стрелки двигают, Shift+стрелки меняют размер. Ctrl/Cmd+Z и Shift+Z работают вне полей ввода и модальных окон. «Готово» возвращает режим чтения. «×» убирает только экземпляр карточки из текущего пространства.

Каталог имеет поиск по названию/C-ID. Один график можно добавить в несколько пространств. Для любого графика доступно представление «Таблица» и описание «О данных». Период применяется к активным карточкам и сохраняется при переключении пространств в текущем сеансе.

Изменения макета автоматически сохраняются в текущем браузере. Это не облачная синхронизация: коллегам передаётся экспорт JSON. На другом устройстве импортируйте файл. Импорт заменяет текущие пространства после предупреждения и допускает undo. Старый файл v1 поддержан. Невалидный файл не изменяет состояние.

Старый сохранённый overview переносится в обычное пространство. Удалённые графики не возникают заново при обновлении приложения. Первый старт без истории создаёт «Мой дашборд», который можно переименовать или удалить; это не фиксированный раздел приложения.

Ограничения: 40 пространств, до 100 карточек в каждом, файл до 1 МБ. Для удобства и скорости держите в одном пространстве только связанные графики. При ошибке localStorage используйте экспорт; повреждённая запись не затирается без резервной копии. Данные, формулы и общая тема через редактор не изменяются.
