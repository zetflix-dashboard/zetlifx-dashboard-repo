# Пространства и редактор

Верхние вкладки — независимые пространства. «+» создаёт любое название; «Меню действий» позволяет переименовать, удалить, экспортировать и импортировать. Вкладки переключаются стрелками + Enter/Space; Home/End переводят фокус на крайние вкладки.

«Настроить» показывает плавающую панель по центру внизу: «Добавить график», «Добавить заголовок», значки отмены и повтора с доступными названиями для скринридеров. Заголовок — самостоятельный текстовый блок сетки: его можно переименовать, переместить, изменить размер и удалить; состояние сохраняется с остальными блоками и участвует в undo/redo. Перетаскивайте за значок с шестью точками в шапке карточки, меняйте размер за любой край или угол (наведение показывает курсор направления, постоянных маркеров нет). Клавиатура на значке перемещения: стрелки двигают, Shift+стрелки меняют размер. Ctrl/Cmd+Z и Shift+Z работают вне полей ввода и модальных окон. В режиме редактирования кнопки «Сохранить для себя» и «Опубликовать для команды» находятся справа в верхней панели. «Сохранить для себя» возвращает просмотр локального макета. Переключатель «Мой макет / Общий макет» расположен по центру верхней панели и недоступен при редактировании. Ручная перезагрузка графиков во время редактирования недоступна. «×» убирает только экземпляр карточки из текущего пространства.

Каталог имеет поиск по названию/C-ID и показывает статус каждого графика: «На дашборде · N», «В другом пространстве» или «Не добавлен». Один график можно добавить в несколько пространств. Для утверждённых графиков (сейчас C03: квартал; C14: жанр; C15: вид доступа) в шапке есть локальный селектор. Он действует только на конкретный экземпляр графика, не меняет глобальный период и сохраняется внутри workspace. Для широких таблиц начальная ширина — 12 колонок; сохранённые размеры не переписываются. RFM: девять столбцов (код сегмента, пользователи, доля пользователей, платежи, доля платежей, платежи на пользователя, среднее число оплаченных месяцев, среднее время с последнего просмотра, пользователи без просмотров) и итоговая строка только для аддитивных показателей, без отдельных R/F/M-оценок. Вместо второй служебной строки карточки рядом с названием показывается приглушённый номер C-ID. Для любого графика доступно представление «Таблица» и описание по значку «i» рядом с названием. Период применяется к активным карточкам и сохраняется при переключении пространств в текущем сеансе.

При открытии виден локальный макет. При отсутствии черновика он совпадает с общим макетом из последней успешной сборки GitHub Pages. Переключатель в верхней панели позволяет посмотреть общий макет. Уже сохранённый в браузере старый макет доступен как черновик. Экспорт скачивает текущий общий макет или открытый черновик. Импорт заменяет черновик после подтверждения и допускает undo, включая импорт старого файла v1.

## Сохранение и публикация для команды

Редактор открывает **Мой макет**: он хранится в текущем браузере. Изменения сохраняются автоматически, о чём сообщает видимый индикатор «Сохранено в браузере». Кнопка «Сохранить для себя» завершает редактирование; она не отправляет правки другим сотрудникам. Переключатель «Мой макет / Общий макет» позволяет сравнить личную версию с опубликованной; при редактировании он блокируется.

Для отправки изменений:
1. Нажмите «Опубликовать для команды». До ввода данных сайт показывает сводку: сколько пространств изменено, какие блоки добавлены, удалены или перемещены, где изменён размер или настройки. Сводка сравнивает локальный черновик с версией, загруженной при открытии страницы.
2. Нужен [fine-grained PAT](https://github.com/settings/personal-access-tokens/new) с владельцем `zetflix-dashboard`, доступом только к `zetlifx-dashboard-repo`, правами `Contents: read and write` и `Pull requests: read and write`. У владельца токена должен быть доступ на запись к самому репозиторию; организация может потребовать одобрения.
3. Введите GitHub-логин `@username` и токен, нажмите «Отправить изменения». Можно сохранить данные в менеджере паролей браузера. Токен не сохраняется в localStorage или sessionStorage.
4. После отправки статус доступен в navbar в любой момент: «Проверяем изменения», «Обновляем общий дашборд» и «Изменения доступны команде». Техническая ссылка на PR находится в подробностях. Публикация считается завершённой, только когда развёрнутый сайт отдаёт версию именно отправленного макета. Когда появится «Изменения доступны команде», обновите страницу.

При сетевой ошибке черновик остаётся в браузере. Повторная отправка того же макета использует прежнюю ветку и PR. Для защиты от ограничений API GitHub статус проверяется с интервалом 60 секунд, с увеличенной паузой при ошибках, при возвращении на вкладку или по кнопке «Проверить статус». Можно закрыть вкладку и посмотреть статус позже в том же браузере.

Если другой участник опубликовал изменения, старая публикация блокируется. Нажмите «Перенести изменения»: при необходимости сначала обновите страницу (черновик остаётся в браузере), затем выберите, какие пространства перенести в актуальную версию. Выбранные пространства заменят одноимённые в новом макете; остальные сохраняются из общей версии. Можно скачать личный черновик до переноса. **Автоматического слияния изменений отдельных карточек пока нет**: перед повторной публикацией проверяйте результат.


Положение, заголовки, пространства и значения фильтров, заданные в редакторе, входят в общий файл. Выбор вкладки и фильтры, меняемые при просмотре, сохраняются отдельно в браузере. Общий макет получает отметку «доступен на Pages», когда загруженная сборка содержит опубликованный файл.

Ограничения: 40 пространств, до 100 карточек в каждом, файл до 1 МБ. Для удобства и скорости держите в одном пространстве только связанные графики. При ошибке localStorage используйте экспорт; повреждённая запись не затирается без резервной копии. Данные, формулы и общая тема через редактор не изменяются.

OLED-тёмная тема использует чёрный фон; кнопки перемещения и удаления видны только в режиме «Настроить». Меню пространств открывается значком трёх точек. Тема переключается кнопкой с луной/солнцем в шапке. При первом посещении следует системной настройке; явный выбор светлой или тёмной темы сохраняется локально и не меняет командные графики или их данные. Подписи, таблицы, оси и подсказки диаграмм переключаются вместе с интерфейсом.

Период задаётся компактным выбором месяцев: нажмите на интервал в панели, выберите начальный и конечный месяц (или готовый год / весь период), затем «Применить». Месяцы выбираются в пределах 2024–2025; «Отмена», Escape и щелчок вне панели закрывают её без изменения фильтра. Для возврата к полному диапазону выберите «Весь период» в календаре. Элементы управления имеют единые размеры и выравнивание. Светлая и тёмная палитры используют сдержанные нейтральные и приглушённые акценты; расчёты и данные остаются прежними.

### Перезагрузка данных

Результаты SQL сохраняются в браузере между загрузками страницы. Изменение конфигурации графика, SQL, выбранных фильтров или используемых файлов данных создаёт новый ключ расчёта. При недоступности хранилища результаты кешируются в памяти вкладки. Круглая стрелка в карточке пересчитывает её для текущих фильтров. Кнопка в верхней панели сбрасывает кэш всех графиков и сразу пересчитывает открытое пространство; остальные пространства пересчитываются при открытии. Во время редактирования общая кнопка скрыта и отключена, а кнопки обновления отдельных графиков скрыты.

Переключатель локального и общего макета использует разные поверхности для двух тем: в светлой — светлая капсула с белым активным сегментом, в тёмной — почти чёрная с графитовым активным сегментом. Вкладки, кнопки, фильтры, карточки и диалоги оформлены в той же системе. Палитры диаграмм и мини-баров таблиц отличаются по теме; данные при переключении не запрашиваются повторно.
