# Режимы работы

STANDARD MODE действует по умолчанию. Любое количество графиков можно создавать, изменять и удалять в пределах их папок: `chart.json`, `query.sql`, `README.md`. Локальные SQL-расчёты, поля результата и локальные фильтры разрешены через существующий контракт. Общий справочник Parquet и определения метрик читаются перед написанием запросов.

Общие источники, SQL-политика, инфраструктура, контракты, оболочка, темы и разделяемый код требуют явной команды активации, установленной корневым AGENTS.md. Режим не переносится между запросами; техническая нормализация PR не изменяет правила активации.

```text
<!-- ZETFLIX_SCOPE
mode: chart
charts: C03 C18
-->
```

Для общей задачи: `mode: admin`, пустое `charts:`. Без блока — chart, IDs выводятся из diff. Если IDs указаны, список должен точно совпадать с изменениями. Дубли и неизвестные режимы запрещены. Один C-ID не может занимать несколько папок.

`Scope changes / scope` запускается с доверенным кодом base SHA, читает пути diff и типы Git-объектов; не запускает код PR. В chart допустимы только три файла каждого C-ID. `Check dashboard / check` проверяет SQL, метаданные, каталог, макет, модульные тесты, сборку и браузерные сценарии. SQL-политика консервативная и не заменяет SQL-парсер или sandbox. Корректность финансовой методики проверяется отдельно по фактам.

Если нужного шаблона, источника или функции SQL нет, остановить эту часть, объяснить ограничение. Не создавать обходной HTML/JS-виджет. Не менять mode ради расширения случайного diff. Required checks на GitHub нужны для обязательного блокирования слияния; Markdown сам по себе не является защитой доступа.
