# Два режима: chart и admin

| Режим | Разрешённые изменения | Пример |
|---|---|---|
| chart, по умолчанию | chart.json и README.md ровно одного каталога C-ID | «C03: покажи прибыль линией» |
| admin, явная задача | Общие компоненты, источники, инфраструктура, несколько графиков в границах запроса | «Admin: добавь источник удержания и шаблон тепловой карты» |

`CHART`, `Chart`, `chart`, «режим чарт», «график» нормализуются в `chart`; `ADMIN`, `Admin`, `admin`, «режим админ» — в `admin`. `batch`, `Batch`, «режим батч» отклоняются. Свободный текст запроса интерпретирует агент с учётом контекста и отрицаний; техническая проверка читает только структурированное описание PR, а не угадывает намерение по наличию слова.

```text
<!-- ZETFLIX_SCOPE
mode: chart
charts: C03
-->
```

Для admin: `mode: admin`, пустое `charts:`. Без блока — chart, C-ID выводится из diff. Дубли блоков/полей, неизвестные режимы и несогласованный C-ID — ошибка.

Запросы «покажи все типы» и «добавь несколько графиков» используют существующие шаблоны и обычные пространства. Даже если несколько C-ID требуют admin, такой запрос ограничен декларациями этих графиков и штатным размещением. Новый источник, шаблон, реестр или тип пространства требует отдельного явного поручения.

## Что реально блокируется
`Scope changes / scope` запускается на `pull_request_target`, checkout строго base SHA, только read permission, без установки зависимостей и запуска кода PR. Он читает diff с обеими сторонами переименований и проверяет тип файлов. chart не может редактировать даже свой AGENTS.md, CSS или новый JS.
`Check dashboard / check` валидирует все JSON, запускает unit-тесты, production build и браузерные тесты. Неизвестные поля, типы, источники и произвольные options отклоняются.

После первого объединения workflow надо сделать эти проверки обязательными в защите main. Изменение описания PR повторно запускает scope. Это не проверка полномочий: тот, кто намеренно выставляет admin и может редактировать репозиторий, меняет общий код. Защита ориентирована на случайные изменения; branch protection — отдельный слой GitHub.

## Если запрос не помещается в chart
Назвать отсутствующий шаблон/источник/поле. Дать конкретную поддерживаемую альтернативу, сохраняющую смысл данных. Пример: «Тепловой карты пока нет. Можно показать эти значения таблицей, если источник уже содержит нужные поля; иначе нужна отдельная admin-задача». Не добавлять скрытую библиотеку и не заменять бизнес-вопрос похожей метрикой.
