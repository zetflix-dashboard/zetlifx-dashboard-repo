# C15 — доля часов оригиналов
Донат по сумме часов подписочного доступа за выбранный период, включая пробные и партнёрские просмотры, без аренды и тестовых пользователей.
Источник: Viewing_Daily → Users (проверка is_test), Content_Titles (origin). Предагрегация по title_id исключает размножение факта. Сегментация по тарифу не поддерживается.
Проверки: общие контрактные тесты и браузерный CI PR.

Локальный фильтр `access`: виды доступа «Подписка», «Пробный период», «Партнерский пакет» либо все три. Выбор ограничивает исходные события просмотра **до** агрегации по тайтлам и действует только на выбранную карточку.
