# C18-advertising

Заполняемость и eCPM по месяцам. Источник advertisingMonthly / Ad_Inventory + Ad_Revenue. Реклама предагрегирована до месяца перед JOIN. Деление на ноль даёт NULL. Полный C18 (доход PL1) ещё не реализован.

Период — месяц 2024–2025. Контракт проверяется `npm run validate:charts`, реальные данные и изменение периода — `npm run test:e2e`. Визуальные настройки предоставляет общий renderer.

SQL хранится в локальном `query.sql`, описание результата — в `data` внутри `chart.json`. При переносе формулы, имена источника и параметры сохранены. Проверена эквивалентность результатов исходному запросу на реальных Parquet.
