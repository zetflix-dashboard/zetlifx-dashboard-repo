# Контракт области chart

Корневой AGENTS.md обязателен. В обычной задаче разрешены только `chart.json` и необязательный `README.md` одного `CXX-slug`.

1. Выбрать C-ID, вопрос, утверждённый dataset и шаблон по `docs/chart-contract.md`. Проверить поля в `src/shared/data/datasets.js`.
2. Один JSON — одна визуализация. Никакого JS/TS/HTML/CSS, локального SQL, зависимостей, вложенных AGENTS, symlink, обработчика событий или произвольного ECharts option.
3. Поддержаны line, bar, combo, scatter, table. Нет подходящего шаблона/источника — предложить доступную альтернативу или отдельную admin-задачу. Не менять общую архитектуру самостоятельно.
4. Регистрация автоматическая, размещение — через каталог в UI. Не менять оболочку ради добавления графика.
5. В README указать вопрос, выбранные поля, ограничения интерпретации и выполненные проверки. Проверить `npm run check` и браузерный сценарий; не добавлять исполняемые тесты внутрь каталога графика.
6. Названия и C-ID не должны вводить в заблуждение. Подписи полей/единицы/NULL приходят из общего каталога, оформление — из общего renderer.
