# Правила графиков — читаются в дополнение к корневому AGENTS.md

1. Один C-ID = один независимый модуль, например `src/charts/C09-retention/`. Не трогай чужие графики и не добавляй вторую тему/фильтр/store.
2. До SQL прочитай `docs/charts.md`, `docs/metrics.md`, `docs/dataset.md`. Укажи вопрос, источники, точное зерно, роль даты и исключения. Проверяй физические Parquet-поля.
3. Модуль декларирует id, заголовок, вопрос, метрики, дату/зерно, поддерживаемые/неприменимые фильтры, загрузку/визуализацию/dispose по общему контракту. Ни один глобальный фильтр не предполагается автоматически применимым.
4. Данные получай через shared data API, только нужные колонки, агрегация SQL до визуализации. Значения фильтров параметризуй; не размножай факты.
5. Покажи loading/error/empty и читаемые подписи. Тестируй изменение фильтров, повторный рендер и очистку ресурсов. Не копируй определение KPI, бери его из shared metrics.
6. В PR фиксируй расчёт, числовую сверку, границы дат, применимость фильтров, реалистично выполненные тесты и известные ограничения.
