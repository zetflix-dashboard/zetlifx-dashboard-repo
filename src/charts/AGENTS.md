# Изолированные графики

Корневой AGENTS.md обязателен. STANDARD MODE разрешает любое количество графиков, для каждого — только `chart.json`, `query.sql`, `README.md` в своём каталоге `CXX-slug`.

1. До SQL прочитать `docs/dataset.md`, `docs/metrics.md` и `docs/chart-contract.md`. Использовать утверждённые Parquet, существующие шаблоны, фильтры и общий renderer.
2. `chart.json` описывает визуализацию и `data`: источники, поля результата с label/unit, зерно, дату, ограничения и фильтры. `dataset` — уникальное имя своего источника. Отдельного dataset.json и ручной регистрации нет.
3. `query.sql` — один запрос SELECT / WITH … SELECT к разрешённым Parquet. Параметры `?`: период (начало/конец), затем локальные срезы в порядке `data.localFilters`. Запрос проходит общую политику; нельзя обходить её JS, HTML, iframe или новым загрузчиком.
4. В README указать вопрос, методику, исключения, ограничения и реальные результаты проверок. При изменении формулы проверить числовые срезы и согласованность с общими определениями метрик.
5. `npm run check`, релевантные браузерные проверки. В обычной задаче не менять shared, инфраструктуру, SQL-политику, исходные Parquet, CI, инструкции или тесты. Форматировать только изменяемые JSON.
6. Новые графики размещать штатным каталогом/редактором; не добавлять скрытые демонстрационные пространства и не менять чужие макеты автоматически.
