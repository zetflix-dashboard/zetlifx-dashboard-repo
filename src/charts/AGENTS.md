# Графики

- Каждый модуль графика задаёт стабильный уникальный ID, заголовок, поддерживаемые фильтры, SQL и параметры ECharts. Когда появится рабочий модуль, используй его контракт как образец.
- Получай параметры из общего состояния фильтров. Подставляй их через параметры запроса. Общие стили и форматирование бери из приложения.
- Загружай только таблицы и столбцы, нужные запросу. Передавай в визуализацию агрегированные результаты запроса.
- При добавлении или изменении графика проверь, что он появляется на дашборде, обновляется при смене фильтра и корректно показывает пустой результат.
