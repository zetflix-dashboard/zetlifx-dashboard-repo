# C20 — RFM на 31.12.2025
Фиксированный срез, общий фильтр периода **не применяется**. Только прямые пользователи с успешными списаниями в 2024–2025, без тестовых и партнёров. Аренда и возвраты в показатель M не включены; M — сумма успешных подписочных списаний. Доля — от общей суммы этих платежей, а не бухгалтерская признанная выручка.

R — количество дней от последнего просмотра на 31.12.2025 (1: >90 либо нет просмотра; 2: 31–90; 3: ≤30).
F — число различных оплаченных месяцев подписочного доступа в 2024–2025 по успешным платежам окна (1: 0–3; 2: 4–11; 3: ≥12), годовые периоды развёрнуты в месяцы.
M — сумма успешных платежей (1: <1500 ₽; 2: 1500–4999 ₽; 3: ≥5000 ₽). Сегмент — конкатенация RFM.
Источники: Users, Billing_Events, Viewing_Daily; факты агрегируются отдельно до соединений. Отображаются девять столбцов: RFM, число пользователей, доля пользователей, успешные платежи, доля платежей, платежи на пользователя, среднее число оплаченных месяцев, среднее число дней с последнего просмотра и число пользователей без просмотров. Значения R/F/M закодированы в сегменте и отдельными колонками не дублируются. Мини-бары по шести количественным столбцам масштабируются независимо. Итоговая строка суммирует только аддитивные пользователи, платежи, доли и число пользователей без просмотров; средние величины нельзя суммировать. Доли и среднее платежей рассчитаны в пределах той же фиксированной платящей когорты. Отсутствие просмотра не заменяется нулём дней: среднее число дней вычисляется только для пользователей, совершавших просмотры. Стартовая ширина таблицы — 12 колонок сетки.
Проверки: общие контрактные тесты и браузерный CI PR.

SQL хранится в локальном `query.sql`, описание результата — в `data` внутри `chart.json`. При переносе формулы, имена источника и параметры сохранены. Проверена эквивалентность результатов исходному запросу на реальных Parquet.
