# C03-financial-trend

Выручка, операционная прибыль и маржа по месяцам. Источник financialMonthly / PL_Control. Это контрольные итоги без независимой сверки по фактам; сегментация не поддержана. Формулы сохранены из исходного MVP.

Период — месяц 2024–2025. Контракт проверяется `npm run validate:charts`, реальные данные и изменение периода — `npm run test:e2e`. Визуальные настройки предоставляет общий renderer.

Локальный фильтр `quarter` выбирает I, II, III или IV квартал **в каждом году общего интервала**. По умолчанию «Все кварталы». Фильтр применяется к контрольной месячной P&L в параметризованном SQL после ограничения глобального периода; не сегментирует показатель по тарифам и не меняет финансовые формулы. Каждый экземпляр C03 имеет собственный выбор.

SQL хранится в локальном `query.sql`, описание результата — в `data` внутри `chart.json`. При переносе формулы, имена источника и параметры сохранены. Проверена эквивалентность результатов исходному запросу на реальных Parquet.
