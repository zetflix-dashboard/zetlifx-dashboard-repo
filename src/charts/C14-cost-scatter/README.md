# C14 — стоимость часа просмотра тайтлов
Scatter: X — суммарные часы подписочного просмотра тайтла, Y — амортизация тайтла за те же месяцы / часы. Каждая точка — один тайтл (название в подсказке). Учитываются подписка, пробный период и партнёрский пакет; аренда и тестовые пользователи исключены. Тайтлы без просмотров исключены: деление на ноль запрещено.
Источники: Content_Amortization и Viewing_Daily, отдельно предагрегированные по title_id; Users исключают тестовых, Content_Titles даёт наименование. Фильтр применяется к месяцу амортизации и дате просмотра.
Проверки: общие контрактные тесты и браузерный CI PR.
