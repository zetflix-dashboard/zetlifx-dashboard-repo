# Общая защищённая область

Только admin. `data/datasets.js` — каталог SQL, полей и единиц; `data/DataClient.js` — DuckDB; `filters/FilterStore.js` — период; `charts/contract.js` — контракт JSON; `charts/templates.js` — единая отрисовка и таблицы; `charts/ChartManager.js` — lifecycle; `ui/format.js` — числовые форматы. В chart-задаче не править эти файлы ради нового графика.
