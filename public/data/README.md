# Parquet-снимок данных дашборда

Здесь хранятся 32 синтетические таблицы учебного видеостриминга; список и зерно в `../../docs/dataset.md`. Один файл = одна таблица, snake_case.parquet. **Файлы в public/ будут доступны каждому посетителю опубликованного сайта, даже если GitHub-репозиторий private.**

Источник описания: «Инструкция.html»; период анализа 2024–2025, история с октября 2023, срез 31.12.2025. При изменении снимка сохранять имена ID как текст, рубли как точные decimal, даты/NULL и бизнес-семантику; не добавлять личные данные и секреты. Не переименовывать таблицы без отдельного совместимого PR.

Перед заменой данных проверять все 32 файла, schema (названия/типы), row count, SHA-256, отсутствие дубликатов PK, внешний ключ, control totals PL_Control/Cash_Control. Обновить manifest и docs/dataset.md, открыть отдельный PR; пересмотреть кеширование версии данных. Запрещены ручные тихие правки Parquet внутри задачи отдельного графика.
