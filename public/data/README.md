# Данные для дашборда

Помести в эту папку подготовленные файлы Parquet. Используй имена в нижнем регистре через подчёркивания, например viewing_daily.parquet. Один файл соответствует одной таблице выгрузки.

Перед обновлением проверь имена и типы столбцов, число строк и контрольные суммы показателей. Идентификаторы сохраняются как текст, деньги как точные десятичные числа, а пропуски как NULL. Файлы в public/data доступны посетителям опубликованного сайта.
