Что изменится для команды

Публикация может занять некоторое время. Ваши изменения сохранятся в браузере.

Опубликовать для всех

Для публикации нужен доступ к командному репозиторию. Данные для входа можно сохранить в менеджере паролей браузера.

Как получить токен
  1. Откройте создание fine-grained токена в GitHub и задайте имя и срок действия.
  2. В Resource owner выберите zetflix-dashboard.
  3. В Repository access выберите Only select repositories → zetlifx-dashboard-repo.
  4. В Repository permissions дайте Read and write для Contents и Pull requests.
  5. Нажмите Generate token и вставьте токен в поле ниже. Если токен ожидает одобрения, его должен одобрить владелец организации.

Общий макет изменился

Ваш черновик сохранён. Выберите пространства, которые хотите перенести в актуальную версию. При совпадении названий выбранное пространство заменит общую версию.
