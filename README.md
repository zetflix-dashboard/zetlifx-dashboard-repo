# Зетфликс — командный аналитический дашборд

Учебный коммерческий дашборд вымышленного видеосервиса «Кинополка» (проектное название «Зетфликс»). **Единственный источник актуального контекста для людей и Codex — этот репозиторий**, а не история отдельного чата.

## Цель и готовый результат
Заменить нестабильный Yandex DataLens собственным модульным веб-приложением: единые стили, навигация и фильтры, независимые модули графиков, проверяемая финансовая методология, совместная разработка через GitHub PR и Codex. Дашборд должен отвечать на управленческие вопросы по прибыльности, подпискам, привлечению, оттоку, партнерствам, контенту, аренде, рекламе, ABC и денежным потокам.

Источник бизнес-требований: предоставленная учебная «Инструкция.html»; её структурированное изложение — [docs/dataset.md](docs/dataset.md), каталог работ — [docs/charts.md](docs/charts.md), расчёты — [docs/metrics.md](docs/metrics.md). Любые отклонения от первоисточника фиксируются как явные проектные решения.

## Состояние проекта
- **Реализовано:** Vite + JavaScript + GridStack + ECharts + DuckDB-Wasm + Parquet, интерактивный редактор макета, каталог графиков, демо C03 и C18, тесты и CI, workflow GitHub Pages.
- **Не реализовано:** остальные обязательные графики C01–C23, полный набор фильтров и сценарии C24. Supabase сейчас не используется.
- **Внимание:** всё в `public/` становится доступным посетителю опубликованного сайта. Сейчас датасет синтетический; никогда не добавлять туда реальные секреты или пользовательские данные.

## Правила для Codex: CHART / BATCH / ADMIN
Любой запрос **по умолчанию** ограничен ровно одним графиком (CHART): можно изменять только его папку `src/charts/CXX-*/`. Явный BATCH/«режим батч» разрешает несколько перечисленных графиков. Явный ADMIN разрешает изменения оболочки. Широкие неоднозначные запросы **не** дают разрешение на ADMIN. PR проверяются GitHub Actions по изменённым путям; подробности — [docs/agent-modes.md](docs/agent-modes.md). Новый график автоматически появляется в каталоге и на дашборде без правок общего JSON.

## Начать работу за 2 минуты
1. Подключи GitHub-репозиторий к Codex / ChatGPT, выбери задачу из [docs/charts.md](docs/charts.md).
2. Напиши: «Прочитай AGENTS.md и связанные документы. Создай график C09 согласно контракту и тестам; работай в отдельной ветке и открой PR».
3. Проверь PR по [docs/contributing.md](docs/contributing.md). Никто не меняет `main` напрямую.

| Путь | Для чего |
|---|---|

## Определение готовности
Результат принимается, если 23 обязательных визуализации работают на одном приложении, применимые глобальные фильтры согласованы, сумма мер корректна при разных разрезах, проверки PL/Cash объяснены, есть схема связей и словарь метрик, не менее трёх выводов и трёх действий с сигналом, контрольной метрикой и ограничением доказательности. C24 и сценарии второго сезона/цены — дополнительные.
