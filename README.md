# Зетфликс — командный аналитический дашборд

Vite + JavaScript + ECharts + GridStack + DuckDB-Wasm. Синтетические Parquet хранятся в репозитории и запрашиваются локально в браузере. Сетевой сервер БД не нужен.

## Что работает
- Оболочка на всю ширину без боковой панели. Пространства создаются, переименовываются и удаляются в UI, а не в исходниках.
- Каталог графиков, изменение размеров и расположения мышью и клавиатурой, undo/redo, автосохранение в этом браузере, экспорт/импорт пространств. Старый layout v1 переносится автоматически.
- Единые шаблоны line, bar, combo, scatter, pie, table, tree, waterfall, funnel и heatmap, таблица значений для каждой диаграммы, общий период 2024–2025, загрузка/ошибка/повтор/пустое состояние.
- C03: контрольные месячные выручка/операционная прибыль/маржа из PL_Control. C18: заполняемость и eCPM; полный доход PL1 ещё не реализован. C14 — стоимость часа по тайтлам (scatter), C15 — доля часов оригиналов (круговая), C20 — фиксированная RFM-сегментация (таблица с мини-барами). Новые графики размещаются через каталог; сохранённые пространства не изменяются автоматически.
- Два режима разработки: chart (один JSON-график) и admin (остальные явно порученные изменения). CI проверяет границы diff и контракт.

## Запуск
Node.js ≥20.19 (CI: 22).

```sh
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
```

`check` валидирует графики, запускает unit-тесты и production build с Pages base. `test:e2e` проверяет эту сборку и реальные Parquet в Chromium. В средах с установленным браузером можно указать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`.

## Работа с ИИ
Прочитать [AGENTS.md](AGENTS.md). Для обычной задачи: «C03: покажи выручку и прибыль линиями». Агент меняет только JSON и README одного графика, автоматически коммитит и открывает PR. Для общей работы: «Admin: добавь источник удержания». Режима batch нет.

Ручное одобрение каждого коммита/PR не требуется. Слияние выполняется после успешных проверок актуальной версии. Требования GitHub и ограничения аккаунта нельзя отменить Markdown-инструкциями. [Настройка защиты и автоматизации](docs/contributing.md).

## Границы текущей версии
Это учебный MVP аналитики: C01–C24 не объявлены все готовыми. Полного исходного словаря 258 полей пока нет в репозитории; сверка финансовых итогов по детальным фактам — отдельная работа. Командный макет публикуется через GitHub, черновики хранятся в браузере. Настройка доступа описана в [руководстве редактора](docs/dashboard-editor.md). В `public/` только синтетика, все файлы публичны на сайте. Первый запуск загружает крупный DuckDB-Wasm; мобильная производительность зависит от устройства.
