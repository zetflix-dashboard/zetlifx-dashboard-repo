# Зетфликс

Командный аналитический дашборд. Планируемый стек — JavaScript, Vite, ECharts и DuckDB-Wasm. Сайт публикуется через GitHub Pages, а браузер выполняет запросы к Parquet.

| Путь | Назначение |
| --- | --- |
| [AGENTS.md](AGENTS.md) | Общие правила Codex |
| [src/charts/](src/charts/) | По одному модулю на график |
| [src/shared/](src/shared/) | Общие SQL-определения и форматирование |
| [public/data/](public/data/) | Файлы Parquet для браузера |
| [docs/metrics.md](docs/metrics.md) | Правила расчёта и сверки |
| .github/workflows/ | Целевое место для проверки PR и публикации Pages |

## Работа команды

Подключи свой GitHub-аккаунт в Codex Cloud, выбери этот репозиторий и опиши изменение. Codex готовит ветку, а ты просматриваешь diff и открываешь PR. В PR коллега проверяет расчёт и поведение фильтров. Для изменения общих правил и проверок нужен отзыв ответственного.

## Первый запуск

Этот каркас содержит документацию. Следующий этап — загрузить Parquet, добавить приложение Vite и реализовать два графика для проверки схемы. Первый можно построить на PL_Control, второй на Viewing_Daily. Затем подключить проверки PR и сборку Pages из основной ветки.

Для защиты основной ветки администратор настраивает обязательные PR, ревью и проверки в GitHub. При добавлении CODEOWNERS укажи реальных ответственных за правила, общий код, данные и CI. Ограничение публикации настраивается в окружении github-pages.
